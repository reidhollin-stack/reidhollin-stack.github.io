Privacy policy

8bit recaps drive. Last updated 27 August 2026.

This application is operated by a single individual for their own personal use. It has no other users, and it collects no information from anyone.

What data the app accesses

The app requests one Google API scope, https://www.googleapis.com/auth/drive.file. This scope grants access only to files the app itself creates. The app uses it to:

  • create a folder in the operator's Google Drive;
  • upload finished video files it has rendered into that folder;
  • write and update two small plain-text status files in that folder;
  • read one small configuration file in that folder, which the operator edits to control the automation.

The app cannot access any other file in the operator's Google Drive, and it does not request any other scope.

How the data is used

Solely to store and retrieve the operator's own generated files. Nothing is analysed, profiled, or used to train anything.

Sharing and disclosure

No Google user data is sold, transferred, or disclosed to any third party. It is never used for advertising, and it is never transferred to any other party except as required to provide the storage function described above.

Retention and deletion

Files remain in the operator's own Google Drive under the operator's control and may be deleted by them at any time. Access can be revoked at any time from myaccount.google.com/permissions, which immediately and permanently ends the app's ability to reach any file.

Security

OAuth credentials are held as encrypted repository secrets in the project's build system and in a permission-restricted file on the operator's own computer. They are never printed, logged, or committed to source control.

Limited Use

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
